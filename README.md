<h1 align="center">OpenSea</h1>

![image](Screenshot.png)

<p align="center">
  OpenSea is a proxy that is built on Scramjet with fallback transports like libcurl, epoxy, wisp and bare with custom protocols.
</p>

## Roadmap

* Multiple Tabs
* URL Scheming
* Settings
* Open any URL

## Self-Hosting

If you decide to self-host this project here's the steps how:

```sh
#clone the repo
git clone https://github.com/yaans-coat/opensea

#cd
cd opensea

#node commands
npm install

#simple server launching
node server.js
```
